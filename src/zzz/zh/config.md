# 必须进行的设置

## 游戏内设置（必须）

1. - [x] `「设置」-「画面」-「显示模式」` 和开发默认分辨率为 `1920x1080 窗口`
        - 游戏分辨率需要是 16:9 比例，如 `1920x1080`，其他分辨率若存在问题请尝试切换
        - 如果使用 `全屏模式` ，则需要保证**显示器分辨率**为 16:9，否则请使用窗口模式
        - 使用过程中请保证游戏图像画面完整，不被任何 `窗口/悬浮加速球/任务栏/FPS显示工具` 所遮挡
2. - [x] `「设置」-「画面」-「帧率」` ~~建议限制在 `30帧`~~，正常配置电脑建议限制在 `60帧`
        - 请不要开启 `无限帧率`，过低帧数、画面卡顿或截图频率不足都可能导致识别出错
        - 画质不需要盲目拉高，以游戏画面稳定、脚本截图流畅为准
3. - [x] 请<font color="red">不要开启</font>任何可能改变显示器颜色的驱动或软件，包括但不限于
        - HDR（通过一条龙启动会自动禁用游戏HDR）
        - 护眼模式/夜间模式
        - N 卡滤镜（快捷键为 ALT+Z ）
        - XBOX 滤镜（快捷键为 WIN+G ）
4. - [x] `「设置」-「输入」-「镜头灵敏度」` 建议先设置为 `2` 或 `3`；首次使用、切换鼠标/手柄或发现转向异常时，请运行 `「一条龙」-「灵敏度校准」`
5. - [x] `「设置」-「输入」-「镜头自动跟随转动」`设置为`「关闭」`，功能[拿命验收](./feat_one_dragon/life_on_line.md)模拟按键以此为基础编写
6. - [x] `「设置」-「其他」-「战斗伤害跳字显示」` 设置为 `关闭` 或 `伤害跳字整合` 可以避免部分情况下伤害数字遮挡画面
7. - [x] `「设置」-「其他」-「字体选项」` 选择 `「全局细体」` 可以有效避免文本识别不准的问题。

::: important 警告
游戏内默认预设的「显示模式」、「镜头自动跟随转动」、「战斗伤害跳字显示」和「字体选项」，不太符合一条龙运行要求，请务必按照本页面进行设置，否则可能导致脚本无法正常运行，如识别失败、任务无法完成等问题。
:::

## 脚本设置（必须）

1. - [x] `「账户管理」-「多账户管理」-「账户列表」` 如果你拥有多个账号，请在这里添加不同的一条龙实例，不同实例之间设置会区分开需要分别填写
2. - [x] `「账户管理」-「多账户管理」-「当前账户设置」-「游戏路径」` 请按照实际情况修改，游戏路径需要选择为<font color="red">绝区零游戏本体</font>的路径(`games\ZenlessZoneZero Game\ZenlessZoneZero.exe`)而非启动器
3. - [x] `「账户管理」-「多账户管理」-「当前账户设置」-「游戏区服」` 请根据你游玩的区服设定，如果切换过区服需要重启一条龙才能识别到游戏画面
4. - [x] `「代码同步」` 使用此功能更新代码版本；使用 exe 启动时默认会自动检测并更新代码，更新后需重启一条龙
5. - [x] `「一条龙」-「预备编队」`
        - 请确保左侧配置的编队名称与游戏内完全一致，编队顺序可以不同
        - 点击页面上的 `「开始」` 后会自动打开游戏内预备编队页面，通过截图识别各编队中的代理人并填入配置
        - 不建议使用默认数字命名编队，<font color="red">数字识别错误率很高</font>，建议改成中文名称
        - 为每个编队选择使用的战斗配置，默认使用全配队通用 [点此查看战斗脚本解释](./feat_game_assistant.md)
6. - [x] `「设置」-「游戏设置」-「按键设置」` 需要根据你游戏中的按键修改键盘或手柄设置（默认和游戏默认一致）

## 脚本更新

一条龙目前主要分为三部分需要更新内容

1. 代码更新（主要）

点击左下角 `「代码同步」` 进行更新；使用 exe 启动时也会按 `自动更新` 设置检测代码更新

更新完后需要重启生效

2. 识别模型和启动器更新

> 更新频次较少

可以在 `「设置」-「资源下载」` 进行模型和启动器的更新，模型名称后面的数字一般是日期或版本标识

3. 运行环境更新（大范围重构）

需要重新下载新版本安装器重新安装；如果代码同步后提示运行环境不兼容，也需要更新安装器或运行依赖

## 启动参数

《绝区零》采用Unity游戏引擎进行开发，高级参数见[Unity说明](https://docs.unity3d.com/Manual/PlayerCommandLineArguments.html)

启用后，脚本在启动游戏时可以控制游戏的分辨率的窗口，避免自己玩游戏后忘记调整设置导致脚本无法运行。
