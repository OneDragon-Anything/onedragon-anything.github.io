## 零号空洞-迷失之地

用于自动化完成`零号空洞-迷失之地`的相关任务。

### 相关配置

1. 挑战副本：选择副本。
2. 刷取目标：决定本周刷到什么程度就停下，默认 `完成悬赏委托`（即每周 8000 积分奖励）。
3. 每周进入次数：只在 `刷取目标` 选 `完成周计划次数` 时才显示，其余目标由脚本自行判断何时结束。
4. 运行记录：显示已完成的目标或本日/本周通关次数，点 `重置记录` 可清空日、周记录重新开始。
5. 挑战配置：选择默认配置，或你在 `挑战配置-迷` 中的配置（见下文）。
6. 每天进入次数：把周目标分摊到每天运行。

### 挑战配置-迷

该标签页可用于编写自定义的挑战配置（一般情况下不需要使用这个功能）

1. 选择已有：点击`选择已有`按钮，从列表中选择已有的配置，再点击`复制`。
2. 新建配置：点击`新建`按钮，输入配置名称。
    - `预备编队`：选 `编队x` 即对应游戏内的编队x。
    - `当期UP代理人`：每周第 1 次优先选择包含当期 UP 的编队。
    - `矩阵行动 - 手动选择代理人`：矩阵行动无法保存默认配队，开启后需要在下方的框里配置代理人，可以用试用角色。
    - `自动战斗`：只在 `预备编队` 使用游戏内配队时生效。配置方式详见 [自动战斗](../feat_game_assistant.md#战斗助手)。
    - `追新模式`：优先选择未满级的调查战略，开启后下方的 `调查战略` 会被禁用。
    - `调查战略` / `周期增益`：进入副本前选择第几个。
    - `商店-使用金币购买`：想速刷不买东西，或在刷成就 `空洞金融大亨` 时关掉。
    - `商店-使用血量购买`：练度低时只建议为绝境武备开启。下方同名的输入框是阈值，血量 ≥ x% 才会购买。
    - `优先选择NEW!藏品`：最高优先级，但不保证识别正确。
    - `只购买第一优先级` / `只购买第二优先级`：刷新多少次数内，只买对应优先级里的藏品。
    - `藏品第一优先级` / `藏品第二优先级`：填写藏品名称。
        - 藏品优先级填写：
            武备、鸣徽、卡牌等选择都写在这，运行过程中会按顺序选择。如果游戏中的选项没有命中优先级的，那么按等级 SABC 来选取。
            - 填写分类，例如 `终结`, `绝境`。这个说明优先选择这个分类，多个选项属于同个分类时，按等级 SABC 来选取。
            - 填写分类 + 等级，以 `分类` + `空格` + `等级` 表述。例如 `终结 S`。
            - 填写具体内容，以 `分类` + `空格` + `名称` 表述。例如 `终结 律动节能器`。
            可以输入的分类、等级、名称，可以在 `assets/game_data/hollow_zero/lost_void/lost_void_artifact_data.yml` 中查看。
    - `区域类型优先级`：填写后，优先选择填写的区域。
        - 区域优先级填写：
            - 优先级每行填写一个，名称与游戏中按TAB显示的一致，例如 `战斗-武备`。 填写后，会 `尽量` 按照优先级进入。
            特殊情况：
            1. 只在视野可见范围内按优先级选择，暂时不做TAB的路径识别，也不做360度旋转识别全部的入口。
            2. 脚本会优先选择只有1种类型的入口，因为混合类型的楼层，容易在寻路过程卡死。
