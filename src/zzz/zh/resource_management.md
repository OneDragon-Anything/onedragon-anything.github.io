本页对应一条龙界面左侧导航底部的 `「资源管理」` 页面，集中管理代码同步、启动器、OCR 识别和各类专用识别模型，并统一配置下载源与网络代理。不熟悉左侧各入口用途时，可先查看[界面导航](./gui_guide.md#资源管理)。

## 下载设置

### 下载源

`下载源` 控制启动器、OCR 和各类识别模型的下载来源，可选 `自动`、GitHub、CNB 或 Gitee。

`自动` 会优先使用上次成功的源，失败或超时后继续尝试其他源；持续低速的源会被自动淘汰。

### 代理设置

`代理设置` 为代码和资源下载配置网络代理。

- `代理类型`：可选 `无`、`个人代理` 或 `GitHub 代理`。
- `代理地址`：按所选类型填写。选择 `个人代理` 时填写本机代理软件的 HTTP 监听地址，例如 `http://127.0.0.1:7890`；选择 `GitHub 代理` 时填写免费代理地址。
- `自动获取免费代理地址`：仅在使用 `GitHub 代理` 时生效，开启后会自动获取；也可以点 `立即获取` 手动刷新，获取失败时可前往 `https://ghproxy.link/` 查看。

如果代码或资源下载失败，可以先回到这里检查代理设置。

### 资源自动下载

`资源自动下载` 开启后，发现资源缺失或有新版本时会跳过确认，直接加入下载队列。

## 更新与下载

### 代码同步

`代码同步` 卡片显示当前代码同步状态，右侧提供：

- `版本记录`：查看最近的提交记录，并把代码回滚到某一次提交。
- `设置`：打开代码设置，包含代码源、代码分支和强制更新等选项。

`设置` 中的常用选项：

- `代码源`：可选 `自动`、GitHub、CNB 或 Gitee；`自动` 优先使用上次成功的源，失败或超时后继续尝试其他源。
- `代码分支`：`主分支` 用于稳定版本，`测试分支` 用于提前体验新功能。
- `强制更新`：同步时把代码更新到最新，并覆盖本地改动。普通用户不改源码时可以开启；如果你正在开发或保留本地改动，请谨慎使用。

`设置` 里还有一组 `开发者选项`：`自动更新` 控制使用 exe 启动时是否自动检测并更新代码，`自定义分支` 用于手动填写分支名。

### 启动器

`启动器` 用于更新一条龙启动器相关资源。首页提示有新启动器时，可以到这里下载更新。

可以在 `原始启动器` 和 `集成启动器` 之间切换，并选择 `稳定版` 或 `测试版` 通道。

### OCR 识别

`OCR识别` 用于下载和切换通用文字识别模型。模型名称后的数字通常是发布日期，一般选择较新的版本。

可用选项会写入当前 OCR 模型配置；如果开启 GPU 选项，会使用 GPU 版本的 OCR 识别配置。

### 专用识别模型

绝区零一条龙还会额外提供以下专用模型：

- `闪光识别`：战斗助手相关识别使用
- `空洞格子识别`：零号空洞相关识别使用
- `迷失之地识别`：迷失之地相关识别使用

如果对应模型缺失，相关功能可能无法正常运行。首页提示有新模型时，可以到这里更新。

## 下载队列

代码、启动器、OCR 和模型更新会统一进入下载队列。

弹窗里可以查看每个任务的进度，也可以单独取消、重试或移除任务；关闭弹窗不会中断下载，同一资源同一目标版本只会保留一个任务。
