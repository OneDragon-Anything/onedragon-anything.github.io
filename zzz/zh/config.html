重要

  • 不同标签页功能不可同时启用
  • 请务必确保你的游戏和脚本根据此页面进行过基础设置，否则可能造成脚本运行失败等问题

首次使用检查清单

按照以下顺序逐项确认，全部通过后即可开始使用一条龙。

不熟悉左侧各入口用途时，可先查看界面导航。

1. 安装与启动

    • 集成启动器：运行 OneDragon-RuntimeLauncher.exe
    • 原始启动器：以管理员身份完成安装后，运行 OneDragon-Launcher.exe
    • 源码运行：完成 uv sync 后，运行 uv run python .\src\zzz_od\gui\app.py

安装细节请参考快速开始。

2. 游戏内设置（必须）

打开游戏，进入设置，逐项确认：

      • 游戏分辨率需要是 16:9 比例，如 1920x1080，其他分辨率若存在问题请尝试切换
      • 如果使用 全屏模式 ，则需要保证显示器分辨率为 16:9，否则请使用窗口模式
      • 使用过程中请保证游戏图像画面完整，不被任何 窗口/悬浮加速球/任务栏/FPS显示工具 所遮挡
      • 请不要开启 无限帧率，过低帧数、画面卡顿或截图频率不足都可能导致识别出错
      • 画质不需要盲目拉高，以游戏画面稳定、脚本截图流畅为准
      • HDR（通过一条龙启动会自动禁用游戏HDR）
      • 护眼模式/夜间模式
      • N 卡滤镜（快捷键为 ALT+Z ）
      • XBOX 滤镜（快捷键为 WIN+G ）

警告

游戏内默认预设的「显示模式」、「镜头自动跟随转动」、「战斗伤害跳字显示」和「字体选项」，不太符合一条龙运行要求，请务必按照本页面进行设置，否则可能导致脚本无法正常运行，如识别失败、任务无法完成等问题。
